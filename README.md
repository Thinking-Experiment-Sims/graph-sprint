# Graph Sprint

Timed fluency drill for translating between x–t, v–t and a–t graphs (constant acceleration, Unit 2).

## Files

- `index.html` — the whole drill (one self-contained file, no dependencies).
- `canvas-embed.html` — HTML to paste into a Canvas page (HTML Editor view).
- `.nojekyll` — tells GitHub Pages to serve files as-is.

## Publish & Live Links

- **Repository:** https://github.com/Thinking-Experiment-Sims/graph-sprint
- **Live Drill:** https://thinking-experiment-sims.github.io/graph-sprint/

## Put it in Canvas

1. Copy the code in `canvas-embed.html`.
2. In Canvas: Pages → + Page → click `</>` (HTML Editor) → paste → Save.
3. Check it in **Student View**. If your institution blocks embedded iframes, the "Open Full Page" button allows students to launch the drill directly.

## Updating

Replace `index.html` in the repo. Changes go live in 1–2 minutes; the Canvas page updates automatically.

## Notes

- Scores and stats are saved in each student's browser (localStorage). They don't sync across devices and you can't see them.
- Keyboard: Pick mode 1–4; Build mode 1–9, Backspace to undo.
